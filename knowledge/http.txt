HTTP 基础知识

HTTP 是客户端和服务器之间传输数据时常用的应用层协议。

GET 通常用于获取资源，POST 通常用于提交数据。客户端发送 HTTP 请求，服务器返回 HTTP 响应。

常见状态码包括：200 表示请求成功，404 表示资源不存在，500 表示服务器内部错误。

JSON 是 Web API 中非常常见的数据交换格式。FastAPI 可以通过 Pydantic 模型接收和校验 JSON 请求数据。

当后端调用外部 API 时，外部 API 的错误不一定会原样返回给前端。如果后端没有正确处理异常，最终前端可能看到 500 Internal Server Error。
