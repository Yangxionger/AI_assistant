FastAPI 学习知识库

FastAPI 是一个基于 Python 的现代 Web 框架，常用于快速构建后端 API。它支持异步编程，并且能够根据代码自动生成接口文档，例如 Swagger UI。

在 FastAPI 中，可以通过 @app.get() 和 @app.post() 定义 GET 和 POST 接口。GET 通常用于获取数据，POST 通常用于向服务器提交数据。例如，前端可以把用户输入的问题通过 POST 请求发送到后端。

FastAPI 经常配合 Pydantic 使用。Pydantic 可以定义请求数据的结构，并自动进行数据校验。如果用户提交的数据格式不符合模型定义，FastAPI 会返回相应的校验错误。

前后端分离开发时，经常会遇到 CORS，也就是跨域资源共享问题。如果前端和后端运行在不同的域名、端口或协议下，浏览器可能会阻止请求。FastAPI 可以通过 CORSMiddleware 配置允许的来源、请求方法和请求头。

HTTP 状态码可以帮助判断接口执行结果。200 通常表示请求成功，404 表示请求的资源不存在，422 常见于请求数据校验失败，500 表示服务器内部错误。

在 AI 应用开发中，FastAPI 可以作为大模型服务的后端入口。前端把用户问题发送给 FastAPI，FastAPI 再调用大模型 API 或 RAG 检索模块，最后把生成结果以 JSON 格式返回给前端。

RAG 系统中，知识库文档通常不会整篇直接拿去做检索，而是先切分成多个较小的文本块，也就是 chunk。每个 chunk 可以单独生成 Embedding，用户提问时再将问题转换成向量，并和知识库中的 chunk 向量进行相似度比较。

Chunk 太大时，可能混入很多无关信息，导致检索不够精确，同时还会增加上下文的 Token 消耗。Chunk 太小时，则可能把一个完整概念切断，使单个文本块的语义不完整。实际项目中需要在语义完整性和检索精度之间选择合适的 chunk 大小。
