Python 基础知识

Python 是一种解释型、通用编程语言，语法简洁，常用于 Web 开发、数据分析、人工智能和自动化脚本。

列表 list 是有序、可变的数据结构，可以使用 append() 在尾部添加元素。字典 dict 用键值对保存数据，例如 {"name": "Alice", "age": 20}。

函数使用 def 定义。函数可以接收参数，也可以使用 return 返回结果。Python 函数可以一次返回多个值。

异常处理通常使用 try/except。它可以避免程序因为可预期的错误直接终止，例如文件不存在、输入格式错误或除零错误。

Path 是 pathlib 模块提供的路径对象。对于文本文件，可以使用 Path.read_text(encoding="utf-8") 读取全部文本内容。
