## 1. Python

**原问题**

一个 Python 函数用 def collect(item, bucket=[]) 收集元素，多次调用后却保留了上次的结果。为什么会这样？如何修正，并说明修正后如何允许调用方主动共享同一个列表？

**3B Base 回答**

````text
函数中的 `bucket` 参数被设置为一个默认值 `[]`，这意味着当函数被调用时，如果没有提供 `bucket` 参数，它将使用一个空列表。因此，每次调用都会操作这个共享的列表，导致结果累积。要修正这个问题，可以将 `bucket` 参数设置为一个可变参数，即使用 `*bucket`，这样每次调用都会创建一个新的列表。此外，为了允许调用方主动共享同一个列表，可以在函数内部创建并返回这个列表。修正后的代码如下：

```python
def collect(item, *bucket):
    bucket.append(item)
    return bucket

# 调用示例
print(collect(1))  # 输出: [1]
print(collect(2))  # 输出: [1, 2]
print(collect(3))  # 输出: [1, 2, 3]
```

这样，每次调用都会创建一个新的列表，并且调用方可以明确地共享同一个列表。
````

**3B Base 回答**

````text
在处理连续子数组的最大和问题时，简单累加所有正数的方法显然是不全面的，因为这忽略了负数对整体和的影响。当数组中包含负数时，连续子数组的最大和可能并不简单地等于所有正数之和。

一种O(n)的解决方法是使用动态规划。定义一个数组dp，其中dp[i]表示以第i个元素结尾的连续子数组的最大和。则有：

- 当dp[i] = nums[i]，如果nums[i] > 0，因为nums[i]本身是正数，直接将其作为子数组和。
- 当dp[i] = dp[i-1] + nums[i]，如果dp[i-1] + nums[i] > 0，说明从dp[i-1]开始的子数组和加上nums[i]后，和会增加，因此更新dp[i]。
````

## 16. 前端基础

**原问题**

网页请求自己的后端时遇到 CORS 错误，为什么用 Postman 请求却成功？解释同源策略由谁执行、预检请求的作用，以及为什么前端添加 Access-Control-Allow-Origin 请求头通常不能解决问题。

**3B Base 回答**

````text
CORS（跨源资源共享）是由浏览器执行的，它限制了不同源的脚本如何访问资源。当浏览器接收到一个跨源请求时，它会先进行预检请求（即先向服务器发送一个 OPTIONS 请求），以检查服务器是否允许该请求。如果服务器允许该请求，它会返回一个响应，其中包含允许的请求头，包括 Access-Control-Allow-Origin。

前端添加 Access-Control-Allow-Origin 请求头通常不能解决问题的原因是，这个头是在服务器端设置的，它只对服务器端的请求有效，对客户端的直接请求无效。Postman 是一个客户端工具，它发送的是直接的 HTTP 请求，所以不需要设置这个头。此外，如果请求是通过 JavaScript 发起的，浏览器会自动处理 CORS，而不会直接发送 OPTIONS 请求。因此，直接通过 JavaScript 发起的请求不会遇到 CORS 问题。
````
